# SoccerApp

Práctica técnica para la gestión de **Ligas de Soccer y Equipos**, desarrollada como una aplicación Full Stack utilizando **Angular, .NET y SQL Server**.

## Descripción
El objetivo de esta práctica es desarrollar una aplicación que permita administrar un catálogo de ligas y equipos, así como su relación de muchos a muchos.

La solución se desarrolló como un proyecto Full Stack compuesto por:

- **Frontend:** Angular
- **Backend:** .NET
- **Base de datos:** SQL Server
- **Control de versiones:** Git / GitHub

## Alcance de la implementación

Debido al tiempo disponible para la entrega, la práctica corresponde a una **implementación parcial** de los requerimientos solicitados.

Se priorizó tener una estructura funcional de extremo a extremo, incluyendo la base de datos, la API y la integración con Angular.

### Requerimientos implementados

- Script SQL para la creación de la base de datos y sus tablas.
- API desarrollada en .NET.
- Endpoints para consulta de información.
- Conexión entre la API y SQL Server mediante Entity Framework Core.
- Vista desarrollada en Angular.
- Consumo de la API desde Angular.
- Visualización de información de equipos en el frontend.
- Relación entre el frontend y backend funcionando de manera integrada.
- Repositorio público en GitHub.

## Ejecución

### Backend
Ingresar a la carpeta:

bash
cd ApiSoccer

Ejecutar:
bash
dotnet run

### Frontend
Ingresar a:
bash
cd AngularSoccer

Instalar dependencias:
bash
npm install

Ejecutar:
ash
ng serve


La aplicación estará disponible en la dirección indicada por Angular al iniciar el servidor.
